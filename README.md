# Data Structures & Algorithms in C++

A structured collection of my Data Structures and Algorithms practice in C++.

This repository contains solutions to problems from **Striver's A2Z DSA Sheet**, **LeetCode**, and other problem-solving platforms.

The goal is to build strong problem-solving skills, understand common DSA patterns, and prepare for technical interviews.

---

## 📚 Topics

- Binary Search
- Strings
- Linked List
- Recursion
- Sorting
- Hashing
- Stack & Queue
- Greedy Algorithms
- Sliding Window
- Two Pointers
- Trees
- Graphs
- Dynamic Programming

## 🧠 Problem-Solving Approach

For each problem, I focus on:

1. Understanding the problem
2. Identifying the underlying pattern
3. Developing the solution
4. Analyzing time and space complexity
5. Implementing the solution in C++
